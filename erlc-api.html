ERLC API V2 (Integrations)

Within this showcase I will show you how to setup the new ERLC API Integration within kite.

  • Head to the Integrations tab on your kite and look for the ER:LC option.
  • Click enable and add in your server key (This is your API key!), then click the Enable button.
  • After you have your key added click on the Authorize Kite button and then follow the instructions on that webpage.
  • After you've fully authorized kite you can go into your command builder, Near the bottom there will be two new blocks called Get ER:LC Server, Run ER:LC Command.
  • You may use either of these blocks, however for the ERLC command, someone must be in your server for the command to run.
  • If you choose to do the server information it'll output random junk, To prevent that from happening, You can paste in the information below.
