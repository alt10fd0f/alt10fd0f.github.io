Dropdown / Select Menu

This is a relatively easy setup to do.

Visit Showcase ↗
  • Add a message block with a dropdown/select menu.
  • Type in your value (Normally just a word or two).
  • Add a comparison condition underneath the dropdown with the following settings:
    • Base Value → {{interaction.value}}
    • Match Condition → The value you put in earlier.
  • Then, connect your flow under the match condition to dictate what happens after a user selects an option on a dropdown!
