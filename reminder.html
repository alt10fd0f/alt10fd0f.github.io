Reminder Command

Within this showcase I will teach you how to make a reminder command. No share codes will be listed at all this is because i said so, and because from my time here i've seen you all become increasingly lazy over simple commands.

Visit Showcase ↗
  • Add the arguments reminder and time. Make both arguments text.
  • Under the command block add a Calculate Value and enter the string of text below. DO NOT CHANGE ANYTHING 
    let raw = lower(trim(string(arg('time') ?? "0m")));
let parts = filter(split(raw, " "), trim(#) != "");
let seconds_list = map(parts, 
  #[len(#)-1:] == "d" ? int(trim(replace(#, "d", ""))) * 86400 : 
  (#[len(#)-1:] == "h" ? int(trim(replace(#, "h", ""))) * 3600 : 
  (#[len(#)-1:] == "m" ? int(trim(replace(#, "m", ""))) * 60 : 
  (#[len(#)-1:] == "s" ? int(trim(replace(#, "s", ""))) : int(trim(#)))))
);
let total_seconds = sum(seconds_list);
let future_time = now().Unix() + total_seconds;
let timestamp = "";
{
  "timestamp": timestamp,
  "seconds": total_seconds
}
  • Set the temp var of the calc block to be data.
  • Under the calculate block add a response message saying... 
    **We've set your reminder for {{var('data').timestamp}}**
You're being reminded of
> {{arg('reminder')}}
  • Under that, add a Handle Errors block (found on the second sidebar).
  • On the handle errors side, add a response message that says You've put a time longer than 30 days.
  • Under the try blocks side, add a wait block, then a dm block under it.
  • Inside of the wait block add {{var('data').seconds}}.
  • In the dm block set the user to {{user}}. And the text to... 
    **This is a reminder you set.**
You're being reminded of
> {{arg('reminder')}}
