Say Command

To make your bot say any message you'd like please follow what I have down below.

Basic Setup For The Command

Step 1

The argument block

  • Get a argument block from the Option Blocks section.
  • Connect it to the top of your command block.
  • Set the argument type to text.
  • Then set the argument to be required.

Step 2

Sending the message

  • Grab a "create response message" block and attach it directly under the command block. (This will be the response message saying that the message has been sent)
  • Type in the text box the following sentence "We've sent the message.". (Able to be whatever you'd like.)
  • Make the response private by scrolling down till you see the switch, Then click it.
  • Put a "create channel message" block under the response one.
  • Put {{channel.id}} in the target channel section.
  • Put {{arg('message')}} in the text part of the channel message.
  • Turn on role pings from the switch underneath.

And boom, Save your command and your ready to go. This is a currently working message command for any bot of your liking. Keep in mind though, this command has no rank lock meaning that any user can use this command.
