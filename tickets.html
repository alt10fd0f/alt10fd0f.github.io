Tickets With Kite

This will be a difficult showcase for Three ticket commands.

Commands Are...

  • Ticket Open
  • Rename
  • Close Request
Visit Showcase ↗

Ticket Open Command

  • Add an argument on top of the command and label it reason.
  • Under the command add a Create Channel block and configure to your desired settings. (Setting the topic to {{` `}} will allow the ticket topic to stay blank.)
  • Add a private response block under saying {{user}} We've created your ticket.
  • Under the response block add a Calculate Value block and paste: 
    {
 "user": user
}
  • Connect a Create Channel Message block and set the target channel to the create channel variable from before.
  • Add your ticket message and two buttons labeled "Claim." and "Close." DO NOT USE MESSAGE TEMPLATES!!!

Claim Button Setup

  • Add a Get Stored Variable labeled ticketclaimeduser (scoped). Scope: {{channel.id}}.
  • Add a comparison condition: Base = that variable, Match = Greater than or equal to, Value = 1.
  • Under match: private response This ticket has already been claimed.
  • Under Else: set stored variable — Scope {{channel.id}}, Operation Increment, Value 1.
  • Response: 
    This ticket has been claimed by {{user}}.
-# {{var('data').user.mention}}
  • Set stored variable claimedby: Scope {{channel.id}}, Overwrite, Value {{user.id}}.
  • Set stored variable ticketchannels: Scope {{channel.id}}, Overwrite, Value {{channel.id}}.

Close Button

  • Get Stored Variable claimedby, scope {{channel.id}}.
  • Comparison: Base = that variable, Match = Contains, Value {{user.id}}.
  • Under match: private response "Are you sure you'd like to delete this ticket?" with buttons Yes. and No.
  • No → private response Okay, we've canceled the deletion.
  • Yes → response: 
    {{user}} has selected to delete the ticket.
-# Ticket will be deleted in
  • Wait block: 15 seconds.
  • Delete channel block: {{channel.id}}.

Rename Command

  • Argument name, max length 50.
  • Get Stored Variable ticketchannels, scope {{channel.id}}.
  • Comparison: Base = variable, Match = Contains {{channel.id}}.
  • Else → response This channel is not a ticket.
  • Match → Get Stored Variable claimedby, scope {{channel.id}}.
  • Comparison: Base {{user.id}}, Match = Contains that variable.
  • Match → Edit Channel: Target {{channel.id}}, Name {{arg('name')}}, Topic {{" "}}.
  • Response: We've changed the name of this ticket to `{{arg('name')}}`.
  • Else → You have not claimed this ticket, You're not able to change the name to this.

Close Request Command

  • Argument reason.
  • Get Stored Variable ticketchannels, scope {{channel.id}}.
  • Comparison: Base = variable, Match = Contains {{channel.id}}.
  • Else → private response This channel is not a ticket.
  • Match → response We've sent a close request for this ticket.
  • Create channel message to {{channel.id}} with button Accept Close.
  • Under button: response {{user}} has accepted the close for this ticket. This Ticket will be deleted in
  • Wait 15 seconds, then delete channel.
