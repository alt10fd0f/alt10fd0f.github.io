Timestamps with Kite

I've seen quite a few people talking about how to do timestamps in kite and everything. So I'm going to list out all of the timestamps that I'm aware of here.

Visit Showcase ↗
→ Will function as a timer and count up from the time it's sent.
→ Will display the time like 5:36 PM.
→ Will display the time with seconds 5:36:00.
→ Will display the date like 01/02/2026.
→ Will display the date in long format like January 2, 2026.
→ Will display both the time and date like January 2, 2026 5:00 PM.
→ Will display like Friday, January 2, 2026 5:00 PM.

Other Timestamps

{{now().In(timezone("America/Chicago")).Format("02/01/2006 03:04 PM")}}

→ Will display the time 02/01/2026 05:43 PM for the timezone that was inputted.
