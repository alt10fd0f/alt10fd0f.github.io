Admin Panel

Banner

A bar shown at the top of every page.

Notification

A small pop-up in the corner. Visitors who already dismissed it will not see it again unless you publish it as new.

Site on / off

When off, visitors see a "be right back" screen. Staff can still use the site. (This is a soft switch for updates: it hides the pages in the browser, it is not a security lock.)

Site features

Turn features on or off for everyone.

Showcases

Create your own showcases here. Visible = everyone sees it. Off = listed but greyed out and cannot be opened. Hidden = only you and staff can see it (marked "hidden" on the site). Changes show up on the site within a few seconds.

Built-in tutorials & blank spots

The original tutorials can be edited too. Pressing Edit opens the current text of the page in the editor (turned into the same simple formatting as your own showcases). Saving replaces the page on the site with your version. Restore original brings the original page back. Show/hide/off for these is still in the "Built-in tutorials" tab.

Built-in tutorials

Visible = everyone. Off = listed but greyed out and cannot be opened. Hidden = not shown to visitors at all (you and staff still see it, marked "hidden"). Your own showcases are managed in the Showcases tab.

Staff members

Staff can edit the banner and notification and see support tickets. Only you can change anything else. Enter a Discord user ID (turn on Developer Mode in Discord, right-click a user, Copy User ID).

Login message (embed editor)

This is what is posted in each user's thread when they log in. It uses Discord's Components V2 layout: one text block (markdown works), an optional avatar on the right, and an optional dropdown.

Where logs go

For each kind of log choose Built-in logs (the bot: a thread per user for logins, the support channel with Reply/Close buttons for tickets), a Webhook trigger (any https URL: a Discord webhook gets a message, any other URL gets the data as JSON), or Both. Webhooks cannot show working buttons or dropdowns, and webhook-only support requests will not appear in the Tickets tab.

Discord connection check

If buttons or dropdowns say "interaction failed", Discord is not reaching the bot. This checks the setup and can set the Interactions Endpoint URL for you.

Open support tickets

Tickets are opened and answered on Discord only (the Reply and Close buttons in the support channel). This list is just a view.
