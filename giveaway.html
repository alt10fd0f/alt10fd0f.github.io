Timed Giveaway Command

Within this showcase I will show you how to make a timed giveaway command. The only share code listed will be the JSON sharecode. Because you all have gotten to lazy.

  • Add a modal under the command block set to the following settings. 
    Question One
  - Text Input
  - Value - prize
  - Label - Prize
  - Placeholder - What is the prize for the giveaway

Question Two
  - Text Input
  - Value - duration
  - Label - Duration (Up to 30 days)
  - Placeholder - Enter the duration (Ex, 5m, 5h, 5d)

Question Three
  - Text Input
  - Value - winners
  - Label - Winners
  - Placeholder - How many winners there can be.
  • Under that add a Set Stored Variable to the following settings. Set the temp var to be count
    • Variable - giveawaycount
    • Operation - Increment
    • Value - 1
  • Under that add a calculate value block and paste in the following (⚠️ Don't change what you don't understand), Then set the temp var to be time 
    let raw = lower(trim(string(input('duration')) ?? "0m"));

let unit = raw[len(raw)-1:];

let clean_num = trim(replace(replace(replace(raw, "d", ""), "h", ""), "m", ""));
let amount = int(clean_num);

let total_seconds = unit == "d" 
  ? amount * 86400 
  : (unit == "h" ? amount * 3600 : (unit == "m" ? amount * 60 : amount));

let future_time = now().Unix() + total_seconds;

"<t:" + string(future_time) + ":R>"
  • Under that add another calculate value and paste in the following. Then set the temp var to be data. 
    {
 "channel": channel.id,
 "guild": guild.id
}
  • Under that, add your channel message and add your channel id to send it to. ({{channel.id}} to send to your current channel. DO NOT USE MESSAGE TEMPLATES!)
  • Then paste in the following in the body of it. 
    - Prize
  - {{input('prize')}}
- Ends By
  - {{var('time')}}
- Hosted By
  - {{user}}
  • Then, Add two buttons. One labeled Enter, Then the other View Participants.

The Enter button

  • Under the Enter button add a user condition, Put the base value to {{user}} and select Has Role and enter your premium role ID (this role will get 2x entry in giveaways.)
  • Under the match condition add a get stored variable to the following settings.
    • Variable - userentrys (This is a newly made variable)
    • Scope - {{var('count')}}{{user.id}}
  • Then put a comparison condition under with the base value set to the variable block above.
  • In the match condition set to Greater Than Or Equal To, 1.
  • Add a response message and type in Uh oh! You have already entered the giveaway!
  • Under the else side add a set stored variable to the following settings.
    • Variable - participants (This is a new variable)
    • Scope - {{var('count')}}
    • Operation - Append
    • Value - 2x {{user.mention}}\n
  • Under that add another set stored variable to the following settings.
    • Variable - userentrys
    • Scope - {{var('count')}}{{user.id}}
    • Operation - Increment
    • Value - 1
  • Under that add a response message saying As a thanks to being apart of our premium program you've been entered 2X!
  • Under the else side of the of the user condition copy over the same setup, However change the value in the participants set stored variable to be {{user.mention}}\n.

The View Participants button

  • Go back up to the create channel message and under the View Participants button add a get stored variable to the following settings.
    • Variable - participants
    • Scope - {{var('count')}}
  • Then add a calculate value block and paste in the following. Then, set the temp var to be data2 
    let raw = string(result('factsdoubt') ?? "");
let lines = split(raw, "\n");

let cleaned = map(lines, join(filter(split(trim(replace(replace(#, "2x", ""), "2X", "")), " "), # != ""), " "));

{
  "cleaned_list": cleaned,

}

Ending the giveaway

  • Then, connect to the side of the create channel message a response message that says Successfully created giveaway!
  • Under that add a calculate value block and paste in the following. 
    let raw = lower(trim(string(input('duration')) ?? "0m"));

let unit = raw[len(raw)-1:];

let clean_num = trim(replace(replace(replace(raw, "d", ""), "h", ""), "m", ""));
let amount = int(clean_num);

let total_seconds = unit == "d" 
  ? amount * 86400 
  : (unit == "h" ? amount * 3600 : (unit == "m" ? amount * 60 : amount));

total_seconds
  • Then, add a wait block below it with the wait durration set to the variable from the calc block above.
  • Under that, add a get stored variable and set it to the following settings.
    • Variable - participants
    • Scope - {{var('count')}}
  • Then, under that add a calculate value block below it and paste in the following. Then set the temp var to be winners 
    let raw = replace(trim(result('riversrun') ?? ""), "\\n", "\n");
let initial_lines = filter(split(raw, "\n"), trim(#) != "");

let expanded_str = reduce(initial_lines, #acc + (lower(#) contains "2x" ? trim(replace(replace(#, "2X", ""), "2x", "")) + "\n" + trim(replace(replace(#, "2X", ""), "2x", "")) + "\n" : trim(replace(replace(#, "2X", ""), "2x", "")) + "\n"), "");

let pool = filter(split(expanded_str, "\n"), trim(#) != "");
let pool_size = len(pool);

let seed = now().Unix();
let jumps = [
  847291, 395812, 104928, 938475, 285739, 582910, 746281, 192837, 657482, 481923,
  928471, 374829, 519283, 837462, 291837, 647382, 182739, 573829, 492817, 738291,
  283746, 918273, 564738, 372819, 849201, 102938, 675849, 293847, 584739, 471829,
  938271, 184729, 657382, 392817, 748291, 283947, 591827, 482910, 837261, 192834,
  374819, 928374, 562819, 847263, 192847, 683749, 294857, 583721, 472819, 938472
];
let draws = pool_size == 0 ? [] : map(jumps, pool[((seed * 7) + #) % pool_size]);

let unique_str = reduce(draws, #acc contains ("|||" + # + "|||") ? #acc : #acc + # + "|||", "|||");
let unique_winners = filter(split(unique_str, "|||"), trim(#) != "");

let req_count = int(input('winners') ?? 1);
let win_count = req_count < 1 ? 1 : req_count;
let max_end = win_count > len(unique_winners) ? len(unique_winners) : win_count;
let final_winners = max_end == 0 ? [] : unique_winners[:max_end];

len(final_winners) == 0 
  ? "No valid entries found." 
  : "🎉 **Winners:** " + join(final_winners, ", ")
  • Under that, add a response message saying the following
