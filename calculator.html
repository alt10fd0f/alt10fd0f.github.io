Calculator Command

To create a calculator command please follow step by step to create a working calculator command.

Blocks involved in command

  • Arguments (3)
  • Comparison Condition (1)
  • Calculate Value (4)
  • Response Message (4)

Step One.

Arguments.

  • Add in three arguments.
  • Name them number_one, operation, number_two and set the number ones a number argument.
  • Attach them to the top of the command.

Operation Argument.

NameValue
Multiplication*
Division/
Subtraction-
Addition+

Step Two.

Comparison Condition

  • Bring in a comparison condition.
  • Add in three new match condition blocks by clicking the + on the block.
  • Set the base value to be {{arg('operation')}}.
  • Go to the match condition parts and add in a different value for each.
  • Set the comparison mode to be Contains.

Step Three.

Calculate Value.

  • Add four calculate value blocks under each match condition.

Add one of these in each of these in the on that matches the operation you have in the match condition above.

  • arg('number_one') / arg('number_two') - Division (/)
  • arg('number_one') * arg('number_two') - Multiplication (*)
  • arg('number_one') - arg('number_two') - Subtraction (-)
  • arg('number_one') + arg('number_two') - Addition (+)

Step Four.

Response Message.

  • Add in a response message block under each calculate value block.
  • Click on the (X) and add in the variable to the correct calculate value block by scrolling to the bottom.
