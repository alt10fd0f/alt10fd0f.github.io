Application Bot

Hello, in this showcase I will teach you how to create a 1-1 recreation of the Appy bot.

Some features in the showcase are...

  • Can limit the user to a certain number of submissions.
  • Will stop the user from doing anything with their own application.
  • Will allow you to open a ticket with the user who submitted the application.
  • Will limit one response per application.

Sending the application

  • Create a scoped variable labeled appsubmis.
  • Add a get stored variable block directly under the command and set to the variable from above and scope to {{user.id}}.
  • Add a comparison condition below and set to the following information.
    • Base Value — Variable from block above.
    • Match Condition — Greater than or equal to, 1
  • Under the match condition add a response message saying "You've already submitted an application at the moment."
  • Under the else side, add a set stored variable block to the following settings.
    • Variable — appsubmis
    • Scope — {{user.id}}
    • Operation — Increment
    • Value — 1
  • Under that, add in a modal to get and place in your questions (see the Modal tutorial).
  • Under the modal block add a response message saying "We've submitted your application".
  • Under that add a calculate value block and input the following: 
    {
 "user": user
}
  • Under that add a Set stored variable block to the following settings.
    • Variable — appid (This is a new variable you'll need to make)
    • Operation — Increment
    • Value — 1
  • Under that add a create channel message and set to your desired settings.
  • Add five buttons under the message named: "Accept, Deny, Accept with reason, Deny with reason, Open ticket with user."

Accept Button

  • Add a user condition under the button set to the following conditions.
    • Base Value — {{user.id}}
    • Match User — Equals, {{var('data').user.id}}
  • Under the match condition add a response message saying "You can not accept your own application".
  • Under the else side add a get stored variable block to the following settings.
    • Variable — appvar (This is a new scoped variable)
    • Value — The variable from the set stored variable block above the create channel message.
  • Add a comparison condition under set to the following settings.
    • Base Value — Variable from block above
    • Match Condition — Equals or greater than, 1
  • Under the match condition have a response message saying "A user's already answered this application."
  • Under the else side add a response message saying "{{user}} has Accepted {{var('data').user.mention}}'s application."
  • Then add a delete stored variable block: Variable appsubmis, Scope {{var('data').user.id}}.
  • Then add a set stored variable: Variable appvar, Scope from set stored variable block above create channel message, Operation Increment, Value 1.

Deny Button

  • Add a user condition under the button: Base {{user.id}}, Match User Equals {{var('data').user.id}}.
  • Under match: response "You can not deny your own application".
  • Under else: get stored variable appvar (new scoped variable) — Value is the variable from the set stored variable block above the create channel message.
  • Comparison: Base = that variable, Match = Equals or greater than 1.
  • Under match: "A user's already answered this application."
  • Under else: "{{user}} has Denied {{var('data').user.mention}}'s application."
  • Delete stored variable appsubmis scope {{var('data').user.id}}.
  • Set stored variable appvar, scope from above, Operation Increment, Value 1.

Accept with reason

  • User condition: Base {{user.id}}, Match Equals {{var('data').user.id}} → "You can not deny your own application".
  • Else: get stored variable appvar.
  • Comparison ≥ 1 → "A user's already answered this application."
  • Else: modal block — Type Short, Identifier acceptreason, Label "Acceptance Reason.", Placeholder "Whats the reason your accepting this submission?"
  • Response: 
    {{user}} has **Accepted** {{var('data').user.mention}}'s application for the following reason.
``{{input('acceptreason')}}``
  • Delete appsubmis scope {{var('data').user.id}}; set appvar Increment 1.

Deny with reason

  • Same user condition and appvar checks as Accept with reason.
  • Else: modal — Type Short, Identifier denyreason, Label "Denial Reason.", Placeholder "Whats the reason your denying this submission?"
  • Response: 
    {{user}} has **Denied** {{var('data').user.mention}}'s application for the following reason.
``{{input('denyreason')}}``
  • Delete appsubmis scope {{var('data').user.id}}; set appvar Increment 1.

Open Ticket with user

  • Add a create channel block under the button and configure to your settings. ({{var('data').user.id}} must be able to see the ticket.)
  • Add a create channel message set to the create channel variable.
  • Add two buttons labeled "Close, Close with reason".
  • Under the close button add a response message: 
    {{user}} has selected to delete the ticket without reason.
