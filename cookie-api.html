Cookie API Transcripts

Within this showcase I will teach you how to build transcripts with cookie API.

Within parts of setting this up you will need your bot token and a API key. DO NOT SHARE THESE WHEN ASKING FOR SUPPORT.

Visit Showcase ↗
  • Start off by heading to the cookie API site.
  • Sign into the site, and go to the sidebar section called API Keys.
  • Create a new API key via the big green button labeled "+ Create Key".
  • Click the copy button to copy your API key, then head back to the kite command with the API block.

Set the API block to the following settings.

  • HTTPS Method — Post
  • URL — https://api.cookie-api.com/api/transcript?channel_id={{channel.id}}
  • Headers — Authorization | [Your cookie API key!]
  • Turn on the JSON body via the switch below.
  • Click on the purple + button and copy and paste the following into it, title.
  • Then, hover your mouse above the right hand side of what you've just entered. And click the purple pencil looking button. Enter whatever you'd like.
  • Go back up to the purple + button again, copy and paste the following bot_token.
  • Then, hover your mouse to above the right hand side and of what you've just entered. And click the purple pencil looking button and enter your bot's token from the discord developer portal.
  • Note: If you regenerate your key you'll have to re add it to your kite bot.
  • Set the temporary variable of the block to be api. And use {{fromJSON(var('api').body()).url}} to get the URL from block.

And there you go! You've created a API transcript system. It's recommended that you have a 5-10 second wait block below it to give it any needed time to process. Have any questions? Ping me down in the discord and I'll help you out!
