How to Store Data for Buttons

Visit Showcase ↗

After buttons the bot acts as if it were a new command. Meaning that any previous data will not be stored, things like argument data, original user data, or any other information from the command.

How to store the data

  • Put a Calculate Value block before the buttons.
  • Follow the format below: 
    {
 "user": arg('user'),
 "reason": arg('reason')
}
    This will change with what type of data you're storing.
  • Set the temporary value of the calculate value block to be data.

How to get the information stored

{{var('data').user.id}}
{{var('data').reason}}
