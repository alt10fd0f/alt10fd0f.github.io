How to Store Data for Buttons

After buttons the bot acts as if it were a new command. Meaning that any previous data will not be stored, things like...

  • Argument data
  • Original user data
  • Or any other information that was previously stored or inputted from the command.
Visit Showcase ↗

How to store the data

  • Put a calculate value block before the buttons.
  • Follow the format below to have your data stored. 
    {
 "user": arg('user'),
 "reason": arg('reason')
}
    This will of course change with what type of data your trying to store.
  • Set the temporary value of the calculate value block to be data.

How to get the information stored

Type in the following format wherever you are trying to retrieve the information.

{{var('data').user.id}}
{{var('data').reason}}

Once again this will of course change with what your using it for and everything.
