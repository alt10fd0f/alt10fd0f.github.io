Intro

This page is maintained and written by ALT10fd0f. This tutorial page was created to help users create complex and advanced commands with their Kite custom bots.

Before getting started, it is recommended that you read the headings below.

Block IDs / Names

You'll often see this line in the tutorials:

  • Replace BLOCK_NAME in {{result('BLOCK_NAME')}} with your actual block's name/id.
  • When replacing the placeholders, the ID you're putting should be of the block that the placeholder is pointing to.

For Example
The result('GET_VARIABLE') is pointing to the Get Stored Variable block. So when replacing the placeholder, you should replace it with the ID of that block.

This will usually (not every time) be referring to a block which is immediately before the block which is using the result function.

Visual Example

Here's a clear demonstration of how Block IDs work between two blocks:

What the image shows:

  • Block 1 — A Create channel message block with the ID readerscreate.
  • Block 2 — A Set stored variable block that needs the result from Block 1. It correctly uses {{result('readerscreate').id}} (the actual ID of Block 1).
  • The version on the right using {{result('CREATE_CHANNEL').id}} is incorrect because CREATE_CHANNEL is just a placeholder, not the real block ID.

Always use the actual ID shown on the block (the small label like readerscreate), not a descriptive name or placeholder.

Copying codeblocks / expressions

The tutorials shown here often make use of Calculate Value blocks whose expressions are shown in codeblocks. To copy the expression simply hover over the top-right corner of the codeblock and click on the clipboard 📋 icon.
